# toolHOSO4 — ระบบโอนข้อมูลระหว่างฐานข้อมูล

เครื่องมือโอนข้อมูลจากฐานข้อมูล **ต้นทาง (Source)** ไปยัง **ปลายทาง (Target)**
โดยเลือกตาม**ช่วงวันที่**และ**ตารางที่เลือก** ระบบจะตรวจว่า Primary Key ใด
ที่ปลายทาง**ยังไม่มี** แล้วเติมเฉพาะแถวที่ขาดเข้าไป (ไม่แก้ไข/ลบข้อมูลเดิม)

## ชนิดฐานข้อมูลที่รองรับ
- **ต้นทาง (Source):** PostgreSQL หรือ MySQL/MariaDB
- **ปลายทาง (Target):** PostgreSQL หรือ MySQL/MariaDB

เลือกชนิดฐานข้อมูลได้อิสระในแต่ละฝั่ง รองรับการโอนข้ามชนิด เช่น PostgreSQL → MySQL
(ระบบสร้าง SQL, การ quote ชื่อ, placeholder และคำสั่ง upsert ให้เหมาะกับแต่ละชนิดอัตโนมัติ
— PostgreSQL ใช้ `INSERT ... ON CONFLICT DO NOTHING`, MySQL ใช้ `INSERT IGNORE`)

## การติดตั้ง / เริ่มใช้งาน
```bash
npm install
npm start
```
เปิดเบราว์เซอร์ที่ **http://localhost:3007**

## หน้าจอการทำงาน
1. **ตั้งค่าการเชื่อมต่อ (index)** — ใส่ IP Server, Port, Database, Username, Password
   ทั้งฝั่งต้นทางและปลายทางในหน้าเดียว ทดสอบการเชื่อมต่อและบันทึกค่าได้
   (รหัสผ่านเข้ารหัสด้วย AES-256-GCM เก็บในเครื่อง)
2. **ข้อมูลพื้นฐาน (Basic Data)**
3. **ข้อมูลคนไข้ (Master Data)**
4. **ข้อมูลประวัติ (Visit Data)**
5. **ประวัติการโอน** — บันทึกการทำงาน 50 ครั้งล่าสุด

แต่ละเมนู (2–4) กดปุ่ม **⚙️ จัดการรายการตาราง** เพื่อเลือกตารางจากฐานข้อมูลต้นทาง
กำหนดคอลัมน์วันที่และคีย์ที่ใช้เทียบได้ (เว้นว่าง = ใช้ Primary Key อัตโนมัติ)

## หลักการโอน
- อ่านคีย์จากต้นทางตามช่วงวันที่ที่เลือก
- ตรวจว่าคีย์ใดที่ปลายทางยังไม่มี (เทียบเป็นชุด ๆ ผ่าน `IN (...)`)
- `INSERT ... ON CONFLICT DO NOTHING` เฉพาะแถวที่ขาด
- รองรับคีย์หลายคอลัมน์, identity/serial/auto_increment และปรับ `sequence` ให้อัตโนมัติหลังโอน (เฉพาะ PostgreSQL)
- โอนเฉพาะคอลัมน์ที่มีร่วมกันทั้ง 2 ฝั่ง (ข้าม generated column ของปลายทาง)

## โครงสร้างไฟล์
```
server.js            Express API (พอร์ต 3007)
src/store.js         จัดเก็บ/เข้ารหัสการเชื่อมต่อ + กลุ่มตาราง
src/db.js            จัดการ connection pool + เลือก engine ตามฝั่ง
src/engines/         โมดูลต่อชนิดฐานข้อมูล (interface เดียวกัน)
  index.js             ตัวเลือก engine
  postgres.js          PostgreSQL (pg)
  mysql.js             MySQL/MariaDB (mysql2)
src/transfer.js      ตรรกะเทียบคีย์และโอนข้อมูล (ไม่ผูกกับชนิด DB)
public/              หน้าเว็บ (ธีมชมพูพาสเทล)
config/              ค่าที่บันทึก (สร้างอัตโนมัติ, ไม่ commit)
```
